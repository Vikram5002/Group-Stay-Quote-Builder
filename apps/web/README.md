# apps/web (Track 2)

React single-page app: quote builder with live contribution meter, quote detail, review queue, availability calendar, imports, policy and evidence pages.

Planned stack (blueprint section 10): React, TypeScript, Vite, React Router, TanStack Query, React Hook Form with the Zod schemas from `@c32/core`, Tailwind CSS, Vitest, MSW and Playwright.

Starts on branch `T2.01`. Build against the contract in [docs/api](../../docs/api/README.md).
